# Archived Synthetic Control Methods session

This directory preserves every tracked file from commit `c23405b` (`thank you slide`) before the sorted-effects session was started on `main`.

It includes the original Quarto configuration, slides, landing page, source literature, images, references, styling, R caches and generated figures. Shared contributor instructions and the PDF theme were copied back into the active project for reuse.

The active site's render list excludes this archive. To rebuild the old session, copy this directory to a separate scratch directory, install its R dependencies (including `scpi`), and run Quarto there. Its cached ggplot objects were created with a different ggplot2 version; a fresh execution may be needed. The historical files themselves are preserved unchanged.
