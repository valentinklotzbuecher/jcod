# Public ACTG175 export

These unchanged files come from the CRAN Git mirror of `speff2trial` 1.0.5,
pinned to commit `9fa954e262daa0dd8d078d8a843537467f7603df`.
`manifest.json` records exact source URLs and SHA-256 hashes.

`ACTG175.txt` contains 2,139 observations and 27 variables. `ACTG175.Rd` is the
package's complete variable dictionary. `DESCRIPTION` records package authors,
provenance and the declared **GPL-2** distribution license. No separate
dataset-specific license was supplied. The files retain their original bytes,
including line endings.

Original trial reference supplied by the package:
Hammer SM et al. (1996), *A trial comparing nucleoside monotherapy with
combination therapy in HIV-infected adults with CD4 cell counts from 200 to 500
per cubic millimeter*, New England Journal of Medicine 335:1081–1090.
Publisher/PubMed full-text access was blocked during this source check, and the
relationship between this export and the entire randomized cohort remains
unverified. Complete 20-week CD4 values in this export should not be mistaken
for proof of complete follow-up in the original trial.

The secondary pilot uses arms 0 and 1 only and the 20-week CD4 endpoint.
See `docs/actg175-pilot.md` for the plan and limitations.
